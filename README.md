# Dot-Net-RestAPI-Project  
A fully functional **.NET Web API (Minimal API)** project built using **.NET 9**, with a **SQLite database**, **CORS enabled**, and complete CRUD operations for the `User` entity.

This backend can be consumed by **any frontend** (Angular, React, Vue, Flutter, Android, iOS, etc.) because **Global CORS is enabled**.

---

## 🚀 Features

### ✔ Fully functional REST API  
- Create User  
- Get all Users  
- Get User by ID  
- Update User  
- Delete User  

### ✔ SQLite Database  
- No installation required  
- Database file auto-creates as `app.db`  
- Very fast and lightweight  
- Perfect for demos, testing, and small apps  

### ✔ CORS Enabled (Global)  
Any domain in the world can access this API, including:
- Angular
- React / Vue
- Mobile apps
- Postman / curl  
- External hosted frontends

### ✔ Tested & Verified  
All endpoints tested successfully using:
- curl (Windows CMD)
- Browser GET requests
- Automatic database persistence
